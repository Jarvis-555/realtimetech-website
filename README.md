# Real Time Tech website

Static HTML, CSS and JavaScript website prepared for GitHub Pages.

## Preview locally

Open `index.html` in a browser or use VS Code Live Server.

## Publish

1. Create a public GitHub repository.
2. Upload everything inside this folder.
3. Open Settings → Pages.
4. Deploy from the `main` branch and root folder.
5. Set `realtimetech.co.ke` as the custom domain.

The contact form creates a WhatsApp message and stores no form data.
